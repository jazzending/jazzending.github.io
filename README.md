# Yiyi's AI Creative Portfolio

Free, static portfolio website for GitHub Pages. It uses a dramatic dark opening section and a light archive layout so colourful project artwork stays prominent.

## Update your work later

Open `projects.js`. Copy one full `{ ... }` project block, then change the title, description, image, and public link. Use a landscape cover image when possible.

For an image you own, place it in an `images/` folder in this repository and set `image` to `images/your-file.jpg`.

## Publish for free

1. Create a new **public** GitHub repository, ideally called `jazzending.github.io`.
2. Upload all files in this folder to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/(root)`, then save.
5. GitHub will publish the site at `https://jazzending.github.io`.

No password, paid hosting, or API key is required.
